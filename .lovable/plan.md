# План: счётчик комментариев, темы роликов и генерация эссе/сценария

## 1. Счётчик комментариев экспертов на карточке
- В выборках материалов (Радар, Новые каналы, Канбан) джойним количество записей `expert_positions` на материал.
- В `MaterialCard` рядом с метриками показываем бейдж «комментарии эксперта: N» (иконка `MessageSquareQuote`), клик ведёт на страницу материала `/materials/$id` к блоку комментариев.

## 2. Раздел «Комментарии» (общий список)
- Новый маршрут `_authenticated/comments.tsx` + пункт в сайдбаре.
- Таблица/список всех `expert_positions` (общий workspace): тип реакции, текст, автор (profiles.full_name), дата, привязанный тезис.
- У каждой записи — ссылка на ролик (`/materials/$id`) и на оригинал YouTube.
- Фильтр по типу реакции и поиск по тексту.

## 3. Кнопка «Создать тему ролика» → воронка темы
Новая сущность `topics` (миграция):
- `topics`: id, title (введённая тема), status (draft → materials_selected → angles_ready → essay_ready → script_ready → done), selected_material_ids uuid[], angles jsonb, chosen_angle text, created_by, created_at. GRANT + RLS shared.

UI:
- Кнопка «Создать тему» в шапке Радара (и на новой странице «Темы» `_authenticated/topics.tsx`).
- Шаг 3.1: поп-ап (Dialog) с вводом темы → server-функция `suggestMaterialsForTopic` (LLM по названиям/саммари материалов) возвращает список подходящих роликов с чекбоксами.
- Шаг 3.2: пользователь отмечает предложенные + может вручную добавить ролик (поиск по названию) → «Утвердить».
- Шаг 3.3: server-функция `generateAngles` — LLM по теме и выбранным материалам предлагает 10 уточняющих тем/углов; пользователь выбирает одну или пишет свою.

## 4. Генерация эссе по теме
- На карточке темы кнопка «Сгенерировать эссе» → server-функция `generateTopicEssay`: берёт выбранные материалы (саммари, тезисы, комментарии экспертов) + промт «Эссе» из Базы знаний (kind=prompt, выбирается продюсером в выпадающем списке) → сохраняет в `topic_essays` (или `content_outputs` с format=essay и topic_id).

## 5. Редактирование эссе и генерация сценария
- Редактор эссе (textarea + сохранение версий, как в материалах), статус «подтверждено».
- После подтверждения — кнопка «Сгенерировать сценарий»: LLM по подтверждённому эссе + промт «Сценарий» из Базы знаний → сохраняется как отдельный output, тоже редактируется.

## Технические детали
- Миграции: таблица `topics` (+GRANT+RLS shared), поля `topics.selected_material_ids`, `angles`; при необходимости `topic_id` в `content_outputs`.
- Server-функции в новом `src/lib/topics.functions.ts` (тонкие обёртки, логика в `topics.server.ts`), LLM через существующий `callLLM` в ai-функциях (вынести в server-модуль для переиспользования).
- Новые страницы: `/topics`, `/topics/$id`, `/comments`; пункты сайдбара в AppShell.
- Каждая страница получает head() с уникальным title/description.

## Порядок реализации
1. Миграции БД (topics, привязка outputs).
2. Счётчик комментариев на карточках.
3. Раздел «Комментарии».
4. Темы: создание → подбор роликов → утверждение → 10 углов.
5. Генерация эссе по промту из Базы знаний + редактор.
6. Генерация сценария по подтверждённому эссе.
7. Проверка сборки и проход сценария в браузере.
